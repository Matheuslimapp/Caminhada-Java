# Caminhada Java – Estudos Práticos

Este repositório foi criado para registrar **meu aprendizado real em Java**, desde os primeiros conceitos até a construção de programas mais estruturados.

Aqui não tem código “bonito por acaso”:  
cada arquivo representa algo que eu estudei, errei, corrigi e aprendi.

Os estudos estão sendo realizados principalmente com base no **curso DevDojo (Java)**, complementados com prática própria.

---

## 🎯 Objetivo
- Aprender Java **do zero**, sem pular etapas
- Criar uma base sólida em lógica de programação
- Evoluir para **Orientação a Objetos**
- Desenvolver raciocínio para resolver problemas com código

---

## 📚 Conteúdo do repositório
- Sintaxe básica do Java
- Variáveis e tipos de dados
- Estruturas condicionais (`if`, `else`, `switch`)
- Laços de repetição (`for`, `while`)
- Métodos
- Exercícios práticos
- Introdução à Programação Orientada a Objetos (em progresso)
